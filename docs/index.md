# Zé Salgados

Interface web de PDV e pedidos. React e TypeScript. Catálogo, pedido e caixa vêm do airtestto, nos domínios Product, Sales e PDV.

O manual deste produto fica neste site. Demanda que também altera o airtestto fica em [wmreis-docs](https://wmreis-labs.github.io/wmreis-docs/mudancas/). O manual do serviço fica em [airtestto-docs](https://wmreis-labs.github.io/airtestto-docs/).

## Desenvolvimento

```bash
npm install
npm start
npm test
npm run build
```

A decisão de permanecer organizado por pacotes está no [ADR](mudancas/adr/2026-04-01-arquitetura-por-pacotes.md).
